# borderless

Mock interviews for Brazilian developers preparing for the international market.

All challenges are language-agnostic. The candidate picks the language; the interviewer scores the
reasoning, not the syntax.

## Structure

```
psp/code_challenge/<session>/
├── interviewee/   # what the candidate receives
└── interviewer/   # the same challenges plus interview notes and scoring
```

| Session | Challenge | Format                                        |
| ------- | --------- | --------------------------------------------- |
| 001     | 1         | Hand-written. Distinct elements.              |
| 001     | 2         | AI-assisted. Rate limiter package.            |
| 001     | 3         | Hand-written. Text formatter.                 |
