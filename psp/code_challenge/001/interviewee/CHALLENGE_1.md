# Challenge 01 — Distinct Elements

**Time box:** 15 minutes
**Mode:** hand-written. No AI, no autocomplete. Documentation search only.
**Language:** any. Use what you are most comfortable with.

## Problem

Given an array `nums`, return the number of distinct elements it contains.

```go
nums := []int{1, 5, 3, 3, 5, 1, 1, 5}
// Output: 3
```

## Constraints

- `nums` can be empty.
- Values fit in a signed 64-bit integer.
- `nums` is not sorted.
- The caller keeps using `nums` after the call.

## What we expect

- Working code.
- A short explanation of your approach.
- A short discussion about complexity.
